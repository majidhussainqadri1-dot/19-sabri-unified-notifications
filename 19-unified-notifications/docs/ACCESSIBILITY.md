# Accessibility and RTL

Objective: WCAG 2.2 AA.

- Semantic landmarks, headings, fieldsets, labels and live regions.
- Keyboard-operable 44px-class controls and visible focus.
- Notification count announced without forcing focus.
- Status is not conveyed by color alone.
- 200%/400% zoom and 320–1920px responsive layouts.
- Reduced-motion and forced-colors support.
- RTL-first page flow with logical CSS properties; English URLs/numbers remain naturally LTR.
- No-JavaScript reading and safe deep links remain functional; JS enhances mutations and live counts.

Staging must cover screen-reader name/role/value, focus return, mixed Urdu/English, Android/iOS representative devices and low-bandwidth behavior.
