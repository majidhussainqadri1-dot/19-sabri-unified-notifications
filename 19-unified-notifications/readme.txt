== Description ==

File 19 consumes versioned factual events from approved domain owners and creates privacy-minimized notification projections. It does not replace domain state, decisions, messages, appointments, publishing, search/discovery or marketplace truth. Runtime access follows current File 00 membership claims; File 20 owns the single bell/shell placement, File 25 owns shared visual tokens and File 26 owns global search/discovery. The platform has one complete free tier and donation/payment status does not alter notification access, priority, delivery or visibility.

Runtime 2.2.0 additionally enforces canonical producer-owner/schema binding, exact same-origin protected links, privileged-action revalidation, coordinated operational containment, provider circuit breakers, privacy export/erasure minimization and the canonical installable folder `unified-notifications-19`.

== Installation ==

1. Install on controlled staging first.
2. Configure encryption/signing material and provider adapters outside the repository.
3. Register producer contracts and File 00 identity assertions (`sabri_membership_claims_v2`).
4. Confirm the File 20 single-bell slot and context controls.
5. Run System Check, functional, security, accessibility, backup/restore and rollback acceptance before production.
