Canonical unified notification center, File 20 bell, preferences, quiet hours, digests, delivery adapters, retries, dead letters, privacy and diagnostics for the Sabri Social Homeopathy Platform.

== Description ==

File 19 consumes versioned factual events from approved domain owners and creates privacy-minimized notification projections. It does not replace domain state, decisions, messages, appointments, publishing or marketplace truth.

== Installation ==

1. Install on controlled staging first.
2. Configure encryption/signing material and provider adapters outside the repository.
3. Register producer contracts and File 00 identity assertions.
4. Confirm the File 20 single-bell slot.
5. Run System Check, functional, security, accessibility, backup/restore and rollback acceptance before production.
