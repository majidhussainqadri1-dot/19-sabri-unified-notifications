== Description ==

File 19 consumes versioned factual events from approved canonical domain owners and creates privacy-minimized notification projections. It does not replace domain state, decisions, relationships, messages, appointments, publishing, marketplace truth or the File 20 application shell.

Runtime 2.1.0 adds an executable four-plan compliance constitution, current File 00 v2 authorization, canonical producer-owner binding, click-time deep-link authorization, device-token ownership protection, non-downgradable security/safety classifications, person/topic/community/course/event/doctor/channel subscription preferences, opt-in creator bulletin caps, complaint/fatigue signals and strengthened RTL/mobile accessibility.

== Installation ==

1. Install on controlled staging first.
2. Configure encryption/signing material and provider adapters outside the repository.
3. Register producer contracts from each canonical domain owner and expose current File 00 v2 identity assertions.
4. Confirm the File 20 single-bell slot and domain deep-link authorization callbacks.
5. Run System Check, functional, security, accessibility, backup/restore and rollback acceptance before production.
